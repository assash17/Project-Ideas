# Project-Ideas-Single-Page-CV

Structured single-page curriculum vitae built with **HTML only** ([roadmap.sh project](https://roadmap.sh/projects/single-page-cv)). Styling is intentionally omitted for a follow-up CSS project.

## Run locally

Open [`index.html`](index.html) in your web browser (double-click the file or use **File → Open**).

When you deploy the site, replace the placeholder `og:url` in `index.html` with your production URL.

## Project structure

```
index.html          # CV page
assets/
  favicon.svg       # Page favicon (also referenced as og:image)
```

## Submission checklist

- [x] Semantically correct HTML structure
- [x] Single-page layout with sections for education, skills, and career history
- [x] SEO meta tags in the head section
- [x] Open Graph tags for social sharing
- [x] Favicon linked in the head section
